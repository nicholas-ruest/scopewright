# ADR-021: Use responsive information density

## Status
Accepted for Scopewright 0.1.

## Context
Scopewright governs full-stack factory executions where a superficially successful optimization can erase required product layers or leave evidence unbound to the actual source. This decision addresses one concrete failure mode in that system rather than establishing a generic preference.

## Decision
The control plane remains usable at mobile width. The production implementation is `frontend/App.css`. The composition root reaches this behavior in the normal request path, and failure is represented as a typed domain or HTTP error rather than an ignored warning.

## Consequences
The design adds an explicit verification obligation and may consume more execution time, but it prevents a fast incomplete result from being represented as a complete product. It also makes the responsible boundary independently inspectable.

## Acceptance and evidence
The criterion is satisfied only when `mobile screenshot` executes against the clean source commit and its receipt is included in the external schema-v2 evidence manifest. A disconnected crate, mocked-only result, or documentation assertion does not satisfy this decision.
