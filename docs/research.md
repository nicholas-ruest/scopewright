# Research and frontier hypothesis
We evaluated ten Ruvnet and five enterprise candidates against current primary sources. The selected set tests a frontier mechanism: combine loop-aware token intervention with risk-weighted evidence allocation while protecting product scope. Baseline A uses a static verification budget. Baseline B adds TokenEconomizer loop intervention. Candidate C adds protected-scope policy and sublinear allocation. Benchmarks measure completed evidence edges per token and decision latency; ablations remove the threshold, allocation and scope guard individually. The hypothesis passes only if C improves useful evidence per token without increasing false completion or weakening the full-product boundary.
