# Prototype acceptance

Scopewright is accepted only as a complete conjunction. The primary browser journey must render a seventeen-stage result after traversing the typed client, middleware, Rust domain, seven exact-pinned upstream operations and durable append. The denial journey must prove the audit count does not change before recovery. The durable journey must find the same sealed record after both browser refresh and backend restart.

Structural counts—25 crates, 25 ADRs, 12 DDD contexts and majority Rust bytes—are necessary but not sufficient. Each crate needs a production dependency edge, typed API, implementation, positive test, failure test and reciprocal design mapping. Each upstream needs immutable provenance and original execution receipts. The external evidence manifest must bind every suite and artifact to the exact clean source SHA. Publication, CI and Gists happen only after local complete PASS and independent semantic review.
